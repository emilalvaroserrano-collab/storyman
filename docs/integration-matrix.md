## Current acceptance limits

The first milestone can be exercised with an existing source-backed job: load its script in `/story-card.html?jobId=<job-id>`, build exact two-sentence scenes, edit and persist individual scenes, generate real ZONOS3 audio, and export/import JSON drafts. A fresh topic cannot pass the OpenCode live writing gate while Zen returns HTTP 429. Canva export needs account authorization and a live permitted design; the local client credentials alone are insufficient.

Canva endpoints and limitations follow the [design listing](https://www.canva.dev/docs/apps/rest-apis/reference/designs/list-designs/), [export creation](https://www.canva.dev/docs/apps/rest-apis/reference/exports/create-design-export-job/), and [export status](https://www.canva.dev/docs/apps/rest-apis/reference/exports/get-design-export-job/) references. Download URLs expire after 24 hours; Storyman caches an accepted export locally before use.
